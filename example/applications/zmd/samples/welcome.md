# 欢迎使用小竹 Markdown

所见即所得：左边悬停滑出文件树，右边悬停滑出目录，`Ctrl+K` 打开命令面板。

> 好的编辑器应该在你写作时消失，只在你需要时出现。

## 一、输入

- 行首打 `# ` 变成标题，`- ` 变成列表，`> ` 变成引用
- 选中文字后用顶部格式条，或者 `Ctrl+B` / `Ctrl+I`
- 拖一张图片进来会插入 `assets/` 下的引用

## 二、结构

| 元素 | 语法 | 快捷键 |
| --- | --- | --- |
| 标题 | `#` | Ctrl+1–4 切视图 |
| 引用 | `>` | Ctrl+Shift+F 聚焦 |
| 表格 | `|` | Ctrl+K 命令面板 |

- [x] 悬停显隐的左右面板
- [ ] 导出 PDF
