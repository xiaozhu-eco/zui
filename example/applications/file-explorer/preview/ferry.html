# 渡口手记

撑船的人姓沈，镇上的人叫他老沈。他只在太阳挨着对岸柳树的时候解缆。

## 渡口没有牌子

一根歪桩，一条缆绳，船就停在缆绳尽头。

- 白天的河不值钱
- 铜铃响一声，就算靠岸
- 回程通常是空的

> 看得太清楚的路，就不需要渡了。

女人留下一根没点的蜡烛，当作加付的船资。蜡烛后来被风吹进河里。老沈没有去捞。
