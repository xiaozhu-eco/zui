五枚颜色，给样本页共用。

--paper
--ink
--accent
--sea
--sand

纸色上的正文，链接用强调色，海水是另一支笔。

源文件 
/* 小竹样本用的一组颜色。预览页会把这些色块画出来。 */

:root {
    --paper: #fbf6ec;
    --ink: #2b261f;
    --accent: #2c6b4e;
    --sea: #3d6f86;
    --sand: #e6dfd0;
}

body {
    background: var(--paper);
    color: var(--ink);
    font-family: "Microsoft YaHei", sans-serif;
}

a {
    color: var(--accent);
}
