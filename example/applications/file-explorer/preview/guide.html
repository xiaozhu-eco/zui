# 小竹样本

这是一份用来试文件预览的样本库。点开文件夹会进入那一层，点开文件会在旁边显示预览。

## 里面有什么

- 文档：两篇笔记、一张账单、一份书架
- 图片：竹标和海岸，都是 SVG
- 代码：一张网页名片、一份主题、一份书目

面包屑可以回到上一层。屏幕变窄以后，位置收成顶部的一排，预览会占满整页，左上角可以返回列表。
